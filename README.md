# Autopage24h

> **English** · [Tiếng Việt](#tiếng-việt)

Official download page for **Autopage24h** — a desktop app (**Windows / macOS / Linux**) that auto-posts to many Facebook pages & groups on a schedule, plus downloads and lightly re-edits video. The interface ships in **14 languages** (`ar bn en es he hi id km ms my pt th ur vi`).

> Commercial software — **all rights reserved**. The source code is **not public**; this repository hosts only the installers (Releases) and this page.

## Download

Get the latest installer for your OS from **[Releases](https://github.com/WABYDEV/autopage24h.com/releases/latest)**:

| OS | File |
|----|------|
| Windows | `Autopage24h-Setup-<version>.exe` |
| macOS | `Autopage24h-<version>.dmg` |
| Linux | `Autopage24h-<version>.AppImage` |

The app auto-checks these **Releases** for new versions and verifies every download by **SHA-512** before installing (nothing installs if the checksum doesn't match). Licensing (3-day trial, then paid) is checked against our own licence server (`api.autopage24h.com`) using signed, per-machine tickets — the update feed and the licence check are independent.

## Features

- Schedule posts across many pages/groups; campaigns (post-once or loop-forever).
- Auto-reply to comments; inbox.
- Download videos (TikTok / YouTube / Facebook / Instagram / Threads / X) and light re-edit.
- Per-machine licensing (firmware-based ID, survives OS reinstall); buy in-app.
