## English

Official download page for **Autopage24h** — a desktop app (**Windows / macOS / Linux**) that auto-posts to many Facebook pages and groups on a schedule, and downloads and lightly re-edits video. The interface is available in **14 languages**.

> Commercial software — **all rights reserved**. The source code is **not public**; this repository hosts only the installers (Releases) and this page.

**Download:** get the latest build for your system from **[Releases](https://github.com/WABYDEV/autopage24h.com/releases/latest)** — Windows `.exe`, macOS `.dmg`, Linux `.AppImage`.

The app checks these Releases for updates and verifies each download's checksum and file type before replacing the running app; nothing is applied if a check fails. The licence (a **3-day free trial**, then paid) is verified separately against our own licence server (`api.autopage24h.com`) per machine, so updates and licensing stay independent.

**Features**

- Schedule posts across many pages and groups; campaigns that post once or loop forever.
- Auto-reply to comments; inbox.
- Download videos (TikTok / YouTube / Facebook / Instagram / Threads / X) and lightly re-edit them.
- Per-machine licence (firmware-based ID that survives an OS reinstall); buy inside the app.

**Support:** questions or problems — reach us through **[autopage24h.com](https://autopage24h.com)**.
