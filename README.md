### English

**What is Autopage24h?**
A desktop app for Windows, macOS and Linux that schedules and auto-posts to many Facebook pages and groups, auto-replies to comments, and downloads and lightly re-edits video from TikTok, YouTube, Facebook, Instagram, Threads and X.

**Is Autopage24h free?**
Every machine gets a **3-day free trial** — no account or email required. After that, buy a licence inside the app.

**Which operating systems are supported?**
Windows, macOS (Apple Silicon) and Linux. Download the matching file from **[Releases](https://github.com/WABYDEV/autopage24h.com/releases/latest)**.

**Can it schedule and post to many Facebook pages and groups at once?**
Yes. Schedule posts across many pages and groups, run post-once or loop-forever campaigns, and auto-reply to comments.

**Can it download videos from TikTok and YouTube?**
Yes — from TikTok, YouTube, Facebook, Instagram, Threads and X, with light re-editing.

**How are updates verified?**
The app checks Releases for new versions and verifies each download's checksum and file type before replacing itself; it never installs a file that fails the check.
